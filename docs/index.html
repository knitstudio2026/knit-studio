＋ 上传商品图 平铺、挂拍、细节图都行

③ 出图设置

不带小装饰丝带、蕾丝蝴蝶结、胸针等，生成时去掉
先用哪个颜色试一张
防比价同一模特同一类场景换位置，防同款图搜
提示：第一张满意再继续，不满意就重出预览，不浪费额度。
「保存到手机相册」会弹出系统分享面板，选「保存图像/保存到相册」才会进图库；没这个选项就点每张图上的「保存」，或长按图片保存。

素材库

图生成后点「存到素材库」就会收在这里，以后打开这个网页随时能看。注意：清除浏览器数据会一起删掉，重要的图记得存相册。
素材库是空的，去「AI 生图」出图后点「存到素材库」

使用说明

· 上传你家毛衣实拍 → 选风格 → 先生成 1 张预览
· 满意点「继续生成剩余」，不满意点「生成预览」重出
· 点图片看大图，手机上长按保存到相册
· 防比价会换脸换场景，避免和同行撞图被比价
长按图片 → 存储到相册
如果预览看着偏暗/发灰，是浏览器深色或护眼模式压的，保存到相册就是原图亮度
